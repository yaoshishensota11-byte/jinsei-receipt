# 人生のレシート

今年日本で生まれた赤ちゃんとして、一生ぶんのお金の流れを体験するブラウザゲーム。
生まれる地域と家庭の年収はランダム。1年ずつ進む人生で8回だけ道を選び、最後に「人生商店」のレシートでお会計をする。

> 「80億分の1」に着想を得たオリジナル作品です。構成・文言・デザインは独自に作っています。

## 遊び方

1. 「生まれる」を押すと、住む地域・家庭の年収・性別・きょうだいが決まる。
2. 人生が1年ずつ自動で進む。等倍で1年10秒（平均寿命まで約14分。選択を含めて1プレイ約20分）。
3. 画面下で **⏸停止／1×〜5×** を切り替える。停止中は「これまでの記録」で年ごとの出来事と収支を振り返れる。
4. 8回の分かれ道（中学卒業後／高校卒業後／最初の働き方／投資／結婚と住まい／転職・独立／親の介護／退職時期）では自動で止まる。
   - 選べる道は家庭の事情で変わる（例：学費の援助がないと「奨学金で大学」「夜間の大学」など）。
   - どの道にも得と損の両方がある。正解はない。
5. 亡くなるとレシートが発行される。**PNGで保存**／**Xで共有**／**詳しい明細を見る** ができる。

- 同じシードなら同じ人生になる：`/?seed=好きな文字列`
- 詳細ページ `r.html#1.<シード>.<選んだ番号>` はURLだけで人生を再現するので、サーバー不要。

### レシートのはんこ

| お釣り（亡くなった時点の純資産） | はんこ |
|---|---|
| -300万円未満 | 赤字閉店 |
| -300万〜500万円 | 人生完済 |
| 500万〜2,000万円 | ギリギリ黒字 |
| 2,000万〜1億円 | 老後安泰 |
| 1億円以上 | 大黒字御礼 |

## ローカル起動・ビルド・テスト

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # dist/ に静的サイトを出力（Vercel はそのままデプロイ可）
npm run test:sim     # 内部高速モードで200人生を自動プレイし、異常値・空の選択肢・再現性を検査
npx vite --port 5199 & npm run test:ui -- 10 60   # ブラウザで10回、60倍速＋自動選択で完走テスト
```

Vercel：リポジトリを読み込めば Vite が自動で認識される（Build `npm run build`、Output `dist`）。有料APIは使っていない。

## 使った統計と出典

| 貯蓄の分布 | 金融経済教育推進機構（J-FLEC）「家計の金融行動に関する世論調査」2024 |

## モデルの主な仮定

- お金は本人の世帯の財布。子ども時代の費用は親が払うので、レシートには載らない。
- 税・社会保険は簡易な累進計算。生活費は家計調査の平均を、世帯の手取りに合わせて伸び縮みさせる（弾力性0.55）。貯えが薄いときは固定費を払った残りで暮らす。
- 65歳以降に貯えが尽きると、持ち家なら家を担保に借り、それもなければ生活保護で不足分を補う。
- 景気後退と株式相場は「同い年みんな共通」の系列で動く。
- 子ども時代（18歳未満）の死亡は扱わない。自殺・虐待などの出来事は扱わない。
- 順位バーは、固定シードの同い年400人（ランダムに選択）と比べた位置。

## 既知の問題

- **統計値の多くが推定。** 一次資料（e-Stat等）で検証・差し替えが必要。
- **赤字で終わる人生がやや多い（ランダムに選んだ場合で約13%が「赤字閉店」）。** 老後の賃貸暮らし×低年金で赤字になりやすい。現実より厳しめの可能性がある。
- 平均寿命がエンジン内で約81歳と、公表値（約84歳）より少し短い（病気による死亡率の上乗せと所得による補正のため）。
- 宝くじの1等は公表の当選確率どおりなので、事実上まず出ない。
- 結果画面で比較集団400人をブラウザ内で計算するため、低スペック端末では一瞬待つ。
- エンジンの式を変えると、古い共有URLの人生が変わる（URLに版番号 `1.` を入れてあるので、次の版で切り替える）。

## 次に改善すべき点（優先順）

1. 推定値を e-Stat の一次データで置き換え、地域を47都道府県単位に細かくする。
2. 選択の結果を「その場で一言フィードバック」して、選んだ意味が伝わる演出にする（動画化にも効く）。
3. OGP画像をレシートから自動生成し、Xで共有したときにレシートが見えるようにする（静的に生成するかEdge Functionを使う）。
4. 同い年比較の集団を事前計算してJSON化し、結果画面の待ちをなくす。
5. 効果音・BGMと、1人生を60秒に短縮する「ダイジェスト再生」（動画化用）。
