# 人生のレシート

今年生まれる赤ちゃんとして、一生ぶんのお金の流れを体験するブラウザゲーム。
生まれる国・場所・家庭はランダム。大きな分かれ道8回と、日々の小さな選択（合計30〜40回）で人生が変わり、最後に「人生商店」のレシートでお会計をする。

> 「80億分の1」に着想を得たオリジナル作品です。構成・文言・デザインは独自に作っています。

## 遊び方

1. タイトルで、生まれる場所のモードを選ぶ。
   - **日本で生まれる**：日本の地域・家庭のどこかに生まれる（日本の公的統計で細かく計算）
   - **主要20か国のどこかで**：日本・米国・中国・インド・ナイジェリア・ドイツなど20か国から均等に選ばれる
   - **世界のどこかで**：実際の出生数の割合で国が決まる（88か国、世界の出生の96%をカバー）
2. 国・生まれた場所（都市か農村か）・家庭の豊かさ・性別が決まる。きょうだいの人数は表示せず、兄や姉は「家には◯歳の兄がいる」と誕生時に、弟や妹は生まれた年に出来事として現れる。その国の5歳未満の死亡率も一文で示す（ゲームでは子ども時代に亡くなることはない）。
3. 人生が1年ずつ自動で進む。何も起きない年は約1秒、出来事のある年は件数に応じて2〜6秒。等倍で1プレイ約10分。
4. 画面下で **⏸停止／1×〜5×** を切り替える。出来事の欄だけがスクロールし、新しい出来事が上に積まれる。停止中は「これまでの記録」を年ごとに振り返れる。
5. 選択場面では自動で止まる。
   - **大きな分かれ道（8回）**：中学卒業後／高校卒業後／最初の働き方／投資／結婚と住まい／転職・独立／親の介護／退職時期。選べる道は国の就学率や家庭の事情で変わる。
   - **小さな選択（1〜3年ごと）**：お小遣い、部活、アルバイト、ボーナスの使い道、副業の誘い、海外への出稼ぎ、家畜を買う、暗号資産、詐欺電話など26種類。国・年齢・状況で出るものが変わる。
   - **人生の出来事から生まれる選択**：結婚したら「子どもを持つか（ほしい／しばらく二人で／持たない）」、授からないときは不妊治療をするか。夫婦のすれ違いでは「話し合う／カウンセリング／別れる」（いきなり離婚はしない）。パートナーの暴力では「相談窓口の支援で家を出る／家族に相談／様子を見る」（描写はせず、日本では相談先 #8008 を表示）。
   - **国ごとの出来事（110種類）**：ナイジェリアの燃料費高騰、インドのモンスーン洪水、米国の医療費、韓国の塾代、フィリピンの海外就労など、その国の暮らしでよく起きることを選択つきで。
   - **結婚の場面**：自分で相手を見つける国では「出会い（食事に誘う・友だちのまま・自分のことを優先）→ 恋人として付き合う（別れることもある）→ 結婚の話（式を挙げて／挙げずに結婚・まだ先にする・別れる）」と段階を踏む。結婚しないと決めたあとでも、まれにいい出会いがある。家族が相手を決めることが多い国では縁談（日本ではお見合い）が来て、一部の国では子どものころに許嫁が決まる。持参金（ダウリー）・婚資（ブライドプライス・マフル）のやりとりも国の習わしで起きる。国ごとの目安は data/world/marriage.json（今は地域ごとの推定）。結婚はゲームの中では18歳以上だけで起きる。
   - **統計にもとづく出来事**：物価の暴騰（通貨の価値が急落）、盗難・強盗、政情不安、紛争による避難、感染症、干ばつ、洪水・地震。起こりやすさはその国のインフレ率・殺人率・政治の安定度などから決まる。物価が荒れやすい国では「ドルや金で貯める」選択も出る。毎年の物価上昇率は、その国で実際に記録された年の値をひと続きで借りてくる（例：「物価が1年で42%上がった（イランで2025年に実際に記録された上昇率）」）。物価で目減りした現金は、レシートに「物価で消えた貯金」として別の行で出る。レシート画像の下の方には「生涯で稼いだお金　約◯◯円」が入り、Xの投稿文も「イランに生まれ、生涯で稼いだお金は約803万円。」のように始まる（本人の稼ぎだけ。パートナーの稼ぎ・年金・手当は含めない）。リンクを共有したときのプレビュー画像は public/og.png（`node scripts/ogimage.mjs` で作り直せる）。
   - どの道にも得と損の両方がある。正解はない。
- **高齢期の電話**：子どもがいる人には「知らない番号からの電話」が来る。多くは詐欺だが、本当に困った子どもからの電話のこともある（確かめると本当だった／急いで助けた）。手元にお金がなければ取られない。ほかに、48歳以降に大人の子どもから「お金を貸してほしい」と頼まれる電話（貸す／断る。貸したお金は返ってくることも、返ってこないこともある）。
6. 亡くなるとレシートが発行される。金額は現地通貨（日本以外は円換算も併記）。画面では1画面に収まる短いレシート（費目は上位7つ＋その他、説明や内訳は省く）を出し、タップすると内訳つきの長いレシートを大きく見られる。保存する画像は長いレシートのまま。**PNGで保存**／**Xで共有**／**詳しい明細を見る** ができる。
7. **子どもとして生まれ直す**（3代目まで）：子どもがいる人は、結果の画面で子どもを選んで次の代を遊べる（続けるかどうかは毎回選べるので、2代で終えてもよい）。次の代は、前の代の人生から決まる：同じ国・地域、家庭の年収は「その子が生まれた年の前の代の夫婦の稼ぎ」、親の年齢ときょうだいは前の代の実際の家族、前の代のあなたは前の代で亡くなった年に亡くなり、残したお金（家を含む）を子どもの数で分けて相続する。借金を残したときは、相続放棄はせず、借金も子どもの数で分けて引き継ぐ（1代目でしっかり稼ぐ意味を持たせるため）。親が家を持っていたときは、自分の分の家を「住み続ける（実家に移って住む）」か「売ってお金にする」かを選ぶ（18歳未満で親を亡くしたときは、そのまま住み続け、18歳で選ぶ）。レシートには「2代目（1代目の第一子）」と、代ごとの稼ぎと残したお金を並べた「家系のレシート」が入る。共有URLは前の代のURLの後ろに「~子どもの番号.選んだ番号」を足した形（今までのURLはそのまま使える）。乱数の流れは変えていないので、1代目の人生は前と同じ（`src/engine/result.ts` の childOf、`src/engine/sim.ts` の Heritage）。

- 同じシードなら同じ人生：`/?seed=好きな文字列`（タイトルでモードを選ぶ）
- 0〜5歳は、成長の場面（初めて歩いた、保育園・幼稚園、七五三、ランドセルなど）が毎年1〜2個出る。日本かどうか・都市か農村か・国の所得水準で中身が変わる。出来事も言い回しもランダム。行事は「その国でほぼ全員が経験するもの」（日本のランドセルなど）は必ず出し、「家庭によって違うもの」（七五三、保育園と幼稚園のどちらか）は確率で出す。ほかの国の行事を足すときもこの決まりで決める。主要19か国（インド・中国・ナイジェリア・アメリカ・フランス・韓国など）は、その国の行事も出る（命名式、アキーカ、洗礼、満月祝い・百日、抓周・トルジャンチ・トイノイ、ハロウィーン、中秋節、ザンクト・マルティン、6歳の入学のシュールテューテなど。資料は `data/world/manual/jinsei_receipt_part8.csv`、ゲームの文は `src/engine/rites.ts`）。宗教や民族で決まる行事は、その人たちの割合くらいの確率にしている。出生届や予防接種の記録は本人の思い出にならないので入れていない。お金は動かさず専用の乱数を使うので、ほかの出来事・選択・金額には影響しない（`src/engine/early.ts`）。ドット絵も合わせて変わる（よちよち歩き、幼稚園の黄色い帽子、七五三の着物・はかま、ランドセル）。
- 働きはじめたら「実家を出る／実家から通って貯める」を選ぶ。実家から通っていると、貯金がたまったころに「そろそろ家を出る？」と聞かれる。自分の子どもが巣立つ年齢になったときも「一人立ちを見送る／実家から通ってもらう／引っ越し代を出す」を選ぶ。
- 親と同居している（実家暮らし・二世帯）ときに親の介護が必要になると、「同じ家で、働きながら自分が見る」が選べる。通いの介護より費用は軽いが仕事は少し減り、きょうだいがいても同居している自分に負担が寄りやすい。
- 離婚やパートナーとの死別のあとは出会いが少なめで、そのまま独り身で暮らすことも多い。
- 亡くなる可能性があるのは20歳から（お金の一生が主題のため、それより前の死亡は扱わない）。
- デート代・結婚式・持参金や婚資は、レシートの「恋愛・結婚」の行にまとめて出る。
- 画面の上に、いま一緒に暮らしている家族（実家にいる間は親ときょうだい、家を出たあとはパートナーと巣立つ前の子ども）の人数を出す。
- 詳細ページ `r.html#6.<モード j|m|w>.<シード>.<選んだ番号>` はURLだけで人生を再現する（サーバー不要）。ゲームの中身が変わって版が上がると、古い版のURLは「このレシートは古い版のため表示できません」と案内してから、遊び直しに誘導する。

### レシートのはんこ

お釣り（亡くなった時点の純資産）を、その国のお金の規模に直した額で判定する（日本の基準）。

| お釣り（日本円の規模） | はんこ |
|---|---|
| -300万円未満 | 赤字閉店 |
| -300万〜500万円 | 人生完済 |
| 500万〜2,000万円 | ギリギリ黒字 |
| 2,000万〜1億円 | 老後安泰 |
| 1億円以上 | 大黒字御礼 |

## 表示の決まり

- 1年が進む時間は、出来事の数にかかわらず一定（等倍で3.2秒）。速さは画面下の倍速ボタンだけで変える。
- 日本以外の国では、レシート画像の各項目・小計・お預かりの下と、グラフの金額に、円の目安を添える。
- 言語の切り替え（タイトル画面・詳細ページ・紹介ページの右上）：ページを Google 翻訳（translate.goog）を通して開き直す。英語・中国語（簡体字）・スペイン語・ポルトガル語・フランス語・ヒンディー語・インドネシア語。レシート画像の中の文字は訳されない（`src/ui/lang.ts`）。

- 暮らしの風景（`src/ui/pixel.ts`）：上の欄の下に、ドット絵の自分と一緒に暮らす家族、住まい（実家・賃貸・持ち家）、街か農村かを描く。年齢（赤ちゃん→子ども→学生→大人→お年寄り）、服装（制服・スーツ・作業着・エプロンなど）、家族の増減、その年の出来事（うれしい年は跳ねる、つらい年は涙）で絵が変わる。その年だけの特別な絵もある：入院中はベッドに寝ている、結婚の年は花嫁衣装とハート、災害の年は雨と浸水、宝くじや相続の年はお金が降る、出稼ぎ中は家族と離れて遠くで働き空に飛行機。絵は画面に出ている年齢に合わせて描く（ゲームは1年先まで計算しているため）。画像ファイルは使わない。

## 紹介ページ（LP）とアイコン

- 紹介ページ：`public/lp/index.html`（公開URL `/lp/`）。ページの中で感想・直してほしい点を送れる欄があり、送り先はGoogleフォーム（ページ下の FEEDBACK に送信先と質問の番号を入れると欄が表示される）。「生まれてみる」ボタンでゲーム（`/`）へ移る。一般の人向けの紹介と、授業での使い方・データの説明を1ページにまとめている。画像は `public/lp/img/`。
- 「こんな人生が、ありました。」：ゲームの中で選んだ6つの人生のレシート（`public/lp/gallery.json`、画像は `public/lp/img/g-*.webp`）。共有URLの版を上げたら `npx tsx scripts/lpgallery.ts > public/lp/gallery.json` で作り直し、`node scripts/lpgalleryimg.mjs` でレシート画像も撮り直す（simtest が古い版のURLを見つけて知らせる）。
- アイコン：地球とレシート（`public/favicon.svg`、`favicon-32.png`、`apple-touch-icon.png`、`icon-192.png`、`icon-512.png`、`site.webmanifest`）。ゲーム・詳細ページ・紹介ページの3つで使う。

## 結果ごとの共有画像

「Xで共有」のURLは `/s/<共有コード>`。Xなどがこのページを読むと、その人の結果から作った画像（「〇〇に生まれ、生涯で稼いだお金は約◯◯円」と、費目の上位・お釣り・はんこのレシート）が出る。人が開くと、結果のページ（`/r.html#<共有コード>`）へ移る。
- 仕組み：Vercel の関数。`api/share.js`（`/s/` を vercel.json で回す）と `api/og.js`（画像を作る。satori と resvg、フォントは Google Fonts から使う文字だけ取る）。中身は `src/server/` にあり、`node scripts/buildapi.mjs`（`npm run build` でも実行）でゲームのコードとデータごと api/ にまとめる。ゲームの中身を変えたら、まとめ直してから push する。
- 読めないコードや古い版のコードは、ふつうの共有画像（`/og.png`）になる。

- **世界：** [data/world/sources.md](data/world/sources.md)。

**推定値について：** 作業環境から官公庁・国連・世界銀行のサイトに直接アクセスできなかったため、GitHub上のミラーやnpmパッケージから取得した。それでも取れない値は推定（各 sources.md と countries.json の `estimated` に明記）。特に、国内の地域分け（places）・結婚年齢・年金加入率と所得代替率・税率・家賃の割合・住宅価格・災害リスクは全88か国で推定値。

## モデルの主な仮定

- 日本以外の国は、日本の詳細な統計を「形」として使い、お金の規模（1人あたりGNIの比 k）と制度の値（寿命・就学率・年金加入率・医療の自己負担・インフォーマル雇用・税・家賃・住宅価格・出生率・結婚年齢・災害）をその国の値に置き換えている。学歴による賃金差は所得の低い国ほど大きくしている。
- 寿命は、日本の死亡率表を標準にした Brass ロジットで、その国の平均寿命に合わせている。
- 子ども時代（18歳未満）の死亡は扱わない。自殺と子どもへの虐待は扱わない。パートナーからの暴力は、本人が被害を受ける側としてのみ、描写をせず事実と選択だけで扱う（確率はWHO・WDIの「過去1年に受けた女性の割合」を生涯の割合に直して年あたりに割ったもの）。
- お金は本人の世帯の財布。子ども時代の費用は親が払うので、レシートには載らない。
- 生活費は家計調査の平均を、世帯の手取りに合わせて伸び縮みさせる。貯えが薄いときは固定費を払った残りで暮らす。
- 日本は65歳以降に貯えが尽きると、持ち家なら家を担保に借り、なければ生活保護。日本以外は、借金が一定額を超えるか老後に貯えが尽きると、家族・親戚・地域の援助で暮らす。
- 景気後退と株式相場は「同い年みんな共通」の系列で動く。順位バーは、同じ国の同い年300人（固定シード、ランダムに選択）と比べた位置。

## 既知の問題

- **世界データの多くの項目が推定。** 特に年金・税・家賃・住宅価格・地域分けは国ごとの実データに差し替える必要がある。
- **リスク指標の一部も推定。** インフレ・殺人率・政治の安定度はWDI/WGIの実データ。DVの割合は51か国が実データで37か国は推定。紛争・洪水・干ばつ・地震の指数と、国ごとの出来事の確率はすべて推定（data/world/sources.md の「リスク指標と国ごとの出来事」に一覧）。
- **日本以外の国は「日本の形の縮尺」なので、国の制度の細部（米国の医療保険、中国の戸籍、インドの留保制度など）は反映していない。**
- 赤字で終わる人生がやや多い（ランダムに選んだ場合、日本で約27%、世界モードで約30%）。
- 選択が多い人生では、等倍で14分ほどかかることがある（多くは10〜11分）。
- 同じ国の比較集団（300人）を結果画面でブラウザ内で計算するため、低スペック端末では一瞬待つ。
- 宝くじの1等は公表の当選確率どおりなので、事実上まず出ない。
- エンジンを変えると古い共有URLの人生が変わる（URLの先頭の版番号で切り替える。今は版2）。

## 次に改善すべき点（優先順）

1. 世界データの推定値（年金・税・家賃・地域分け）を、ILO・OECD・国連の一次データで置き換える。
2. 選択の直後に「その選択で何が変わったか」を一言見せる演出を強める（動画化にも効く）。
3. 国ごとの「あるある」な小さな選択を増やす（例：中国の受験、インドの盛大な結婚式、米国の医療保険、ドイツの職業訓練）。
4. レシートの最後に「同じ選択を日本でしていたら」を1行で比較し、知らない国の人生を自分ごとにする。
5. OGP画像をレシートから自動生成し、Xで共有したときにレシートが見えるようにする。
