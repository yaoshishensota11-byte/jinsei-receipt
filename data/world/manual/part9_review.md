# 第9部（国ごとの出来事の確率）の確認メモ

Gemini の Deep Research の結果を1回分ずつ確かめ、取り込むときの判断をここに残す。
全回そろってから、確率（annualProb）と根拠（basis）をまとめて書き換え、共有URLの版を上げる。

## 1回目（日本・アメリカ 10件）jinsei_receipt_part9_01.csv

| 出来事 | 値 | 判断 |
|---|---|---|
| jpn_tenkin | 空欄 | 再調査。JILPT 2017 の企業調査に「転勤のある正社員の割合」があるはず |
| jpn_kaigo | 空欄 | 再調査。就業構造基本調査2022に「過去1年に介護・看護のため離職した人（約10.6万人）」「介護をしている有業者（約365万人）」がある |
| jpn_earthquake | 空欄 | 再調査。気象庁の震度6弱以上の観測回数と、市区町村の人口から計算できる |
| jpn_heavy_rain | 空欄 | 再調査。水害統計の浸水棟数（年平均）÷ 住宅数 |
| jpn_seishain | 0.063（年率） | 使える（リクルートワークス研究所。民間の大規模パネル調査）。不本意非正規から正規への年間転換率。場面は「登用試験の打診」なので、確率はこの値以下にする |
| jpn_chugaku_juken | 0.20（首都圏） | 出典がまとめサイトなので、首都圏模試センターの公表値で確かめる。全国の値が必要 |

| usa_student_loan | 0.421 | 二次情報（educationdata.org）。NCES の immediate college enrollment rate で確かめる |
| usa_layoff | 0.10 | Gemini の概算（月1%×12）。JOLTS の年合計で確かめる。場面は「部署ごとの解雇」なので、確率はこの一部 |
| usa_childcare | 15,636ドル/年 | 金額のみ。利用割合は未取得 |

### 追加の回答（空欄4件の材料）
| 出来事 | 値 | 判断 |
|---|---|---|
| jpn_tenkin | 5,827 | 調査の回答者数で、転勤の割合ではない。使えない。再調査 |
| jpn_kaigo | 介護離職 10.6万人/年、介護しながら働く人 364.6万人 | 使える。働く人（40〜64歳 約3,500万人）の約1割が介護中。平均の介護期間 約5年（生命保険文化センター）とすると、新たに始まるのは年2%前後。場面は「離れて暮らす親が倒れた」なのでその一部として、今の年1%は妥当な範囲 |
| jpn_earthquake | 震度6弱以上 20年で43回（年約2回） | 回数は気象庁のデータ（転載サイト経由）。1回で揺れる人口が分かれば年率にできる。今の年0.8%は「1回あたり約500万人」に当たり、やや多めの可能性 |
| jpn_heavy_rain | 2023年の被害建物 約3.1万棟 ÷ 住宅 6,505万戸 = 年0.05% | 使える。今の年0.5%は約10倍多い。過去10年の平均（2019年など大きな年を含む）を確かめたうえで、年0.1%前後に下げる |

### 見つかった食い違い
- jpn_seishain（正社員登用の話）の条件が「働いている」だけで、正社員の人にも「契約社員として働く職場で…」と出てしまう。条件を「非正規で働いている」にする（取り込みのときに直す）。
