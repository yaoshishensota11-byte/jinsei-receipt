## 2回目（主要20か国）jinsei_receipt_part11b.csv

Manus のクレジットが途中で尽き、運転手の給料・歯の治療の保険・歯の治療費・めがねの4項目は手つかず（20か国とも空欄）。要約は part11b_summary.md。

| 項目 | 値あり | 判断 |
|---|---|---|
| outbound_mobility_ratio（留学） | 20/20（UNESCO） | 使える。ベトナム4.6%、パキスタン4.2%、日本0.9%、アメリカ0.7%。ナイジェリアは2011年、エチオピアは2014年と古い |
| study_abroad_annual_cost | 18/20 | 英国の学生ビザで求められる生活費の額（年10,539ポンド）などで、実際にかかる学費と生活費ではない。使わない |
| study_abroad_by_income（日本） | 家庭の年収の区分ごとの割合 | 「留学した人のうち、どの年収の家が多いか」の内訳で、年収ごとの留学する割合ではない。年収が高い家ほど多い、という傾向だけ使える |
| single_parent_household_share | 10/20 | 使える。フランス26.6%、アメリカ25.1%、日本13.4%、韓国8.6%、中国3%。残り10か国は推計が要る |
| single_parent_poverty_rate | 10/20（OECD ほか） | 使える。ブラジル61%、アメリカ50%、日本44%、ドイツ29%。インド・中国は2011年と古い |
| sickness_benefit_status | 20/20 | 使える。アメリカ・韓国・コンゴ民主共和国は国の制度なし。ただしインドなど「ある」とされた国も、対象は正規に雇われた人だけ。ゲームではインフォーマルで働く割合（countries の informalEmploymentShare）と組み合わせる |
| long_sick_leave_share | 3/20 | 短い欠勤も含む近い値だけ。使わない |
| doctor_wage_ratio・med_student_high_income_share・med_school_entrants_share | 医師の給料は5か国、医学部生の家の年収は日米だけ、医学部の入学者の割合は0か国 | 医師の出来事を国ごとに作るには足りない。保留 |
| wage_ratio_*（職業の給料） | 製造業だけ20か国。教員4・公務員2・看護師0・運転手0 | 職業を細かくするには足りない。保留 |
| dental_*・glasses_cost | 0/20（調査が終わらなかった） | 保留。別のAIで聞き直す候補 |
